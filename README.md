# ГосДок Ассистент

Прототип для демонстрации возможностей локальной языковой модели в работе органов власти и
подведомственных учреждений. Модель запускается на сервере организации, документы не покидают
контур.

Три сценария:

| Раздел | Что показывает |
|---|---|
| **Проверка по нормативной базе** | Пользователь вставляет положение, регламент или ТЗ и нажимает «Проверить». Система находит ссылки на отменённые и изменённые акты, объясняет, чем они заменены, и предлагает актуальную редакцию. Правки подсвечиваются на экране (удалённое зачёркнуто, добавленное выделено); в .docx выгружается чистовик без пометок. |
| **Ответ на обращение** | По входящему обращению и позиции исполнителя готовит проект ответа по 59-ФЗ / 8-ФЗ. Недостающие сведения помечаются `[заполнить: …]`. Выгрузка в .docx. |
| **Перенос таблиц** | Переносит записи из выгрузки (Excel, CSV) в целевую форму: разбор ФИО и адресов, нормализация дат и телефонов, классификация, расчёты. Выгрузка в CSV для Excel. |

Для каждого сценария подготовлены образцы — кнопки «Подставить образец» на странице.
Исходные документы лежат в `backend/app/data/examples/docs/` (.docx для документов и обращений,
.csv/.tsv для таблиц), их текст разбирается в `examples/*.json` командой `make examples`; тест
проверяет, что JSON не разошёлся с исходниками. Для документов на проверку рядом лежит эталонная
редакция (`*.expected.docx`) — на странице она открывается вкладкой «Эталон юриста», чтобы сравнить
с правками модели. Исходный .docx образца можно скачать и показать сценарий загрузки файла.

## Архитектура

```
браузер ──► frontend (nginx + React) ──/api──► backend (FastAPI) ──► PostgreSQL
                                                    │
                                                    └──► LLM: любой OpenAI-совместимый API
                                                         (Ollama, vLLM, llama.cpp, облако)
```

- **Проверка по нормативке** устроена в два шага: ссылки на акты находятся детерминированно по
  справочной базе `backend/app/data/norms.json` (статус, дата утраты силы, замена, ключевые нормы),
  а модель только переписывает текст по этим фактам. Так модель не «придумывает» статусы законов.
  В эксплуатации справочник подключается к официальному источнику (pravo.gov.ru, СПС).
- Ответы модели передаются потоком (SSE), пользователь видит текст по мере генерации.
- Доступ только для авторизованных пользователей; учётные записи ведёт администратор в разделе
  «Пользователи». Сессия — подписанный JWT в httpOnly-cookie.

## Быстрый старт

Нужны Docker с Compose и сервер модели с OpenAI-совместимым API.

```bash
cp .env.example .env        # заполнить SECRET_KEY, ADMIN_PASSWORD, POSTGRES_PASSWORD
ollama pull qwen3:14b       # если модель на хосте; запускать с OLLAMA_CONTEXT_LENGTH=16384
make up-local               # собрать и запустить
```

Сайт: http://localhost:8080, вход — `ADMIN_USERNAME` / `ADMIN_PASSWORD` из `.env`.

Модель в контейнере на GPU (нужен NVIDIA Container Toolkit): в `.env` задать
`COMPOSE_PROFILES=ollama` и `LLM_BASE_URL=http://ollama:11434/v1`, затем
`docker compose --env-file .env -f docker/docker-compose.yml exec ollama ollama pull qwen3:14b`.

### Готовые образы

CI собирает образы при каждом push в `main` и при тегах `v*`:

- `ghcr.io/fgeeha/light-gosdoc-assistant-backend`
- `ghcr.io/fgeeha/light-gosdoc-assistant-frontend`

На сервере достаточно `docker/docker-compose.yml`, `.env` и `make up-prod`.

### Подключение другого провайдера модели

| Сервер | `LLM_BASE_URL` | `LLM_EXTRA_BODY` |
|---|---|---|
| Ollama | `http://host:11434/v1` | `'{"reasoning_effort":"none"}'` для Qwen3 |
| vLLM | `http://host:8000/v1` | `'{"chat_template_kwargs":{"enable_thinking":false}}'` для Qwen3 |
| llama.cpp server | `http://host:8080/v1` | — |
| Облачный провайдер | URL провайдера, ключ в `LLM_API_KEY` | — |

## Разработка

```bash
make install        # uv sync + npm ci
make run            # бэкенд на :8000 (SQLite)
make run-frontend   # фронтенд на :5173 с прокси /api
make check          # ruff, tsc, pytest
make bench MODELS="qwen3:14b gemma3:12b"   # сравнить модели на образцах
make examples       # пересобрать тексты образцов из docs/
```
